# SkillSync AI 🚀
### GPS for Career Growth

## 💡 The Core Problem
Many engineering students from regional colleges lack direct access to personalized industry mentorship. They often struggle to pinpoint the specific technical skill gaps preventing them from matching modern developer expectations.

## 🤖 How It Works (AI Core)
SkillSync AI leverages automated Natural Language Processing (`spaCy` & `scikit-learn` algorithms) to programmatically analyze user resumes and public GitHub repositories. It flags critical engineering skill gaps, visualizes proficiency spreads via interactive charts, and generates intelligent resume optimization tracks using the Gemini LLM.

## 🛠️ Tech Stack
- **Backend Architecture:** FastAPI
- **Frontend & Dashboard:** Bootstrap & Chart.js
- **AI/NLP Engine:** Python, spaCy, scikit-learn
